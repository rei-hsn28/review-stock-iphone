復習ストック iPhone版

このフォルダをHTTPS対応の静的サイトホスティングに配置すると、iPhoneのSafariから使えます。
フォルダ内のファイルをすべて同じ場所に置いてください。

iPhoneでの使い方
1. 公開後のURLをSafariで開く
2. 共有ボタンをタップし、「ホーム画面に追加」を選ぶ
3. 「Webアプリとして開く」が表示されたらオンにして「追加」

初回にページを開くと、アプリ本体を端末にキャッシュします。以降はオフラインでも開けます。
復習記録はiPhone上のブラウザにだけ保存され、他の端末とは同期されません。
タスク追加時と、画像が未取得の既存タスクを開いた時に、日本語版Wikipediaで画像を自動検索します。検索に使うタスク名がWikipediaへ送信され、取得した画像URLは復習記録と一緒に端末内へ保存されます。画像の検索・表示にはインターネット接続が必要です。
